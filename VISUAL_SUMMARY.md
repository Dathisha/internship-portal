## 🚀 Quick Navigation

### How to Get Started

```
STEP 1: BACKEND SETUP (2 min)
├─ cd backend
├─ composer install
├─ cp .env.example .env
├─ php artisan key:generate
├─ php artisan migrate
└─ php artisan serve

STEP 2: FRONTEND SETUP (2 min)
├─ cd frontend
├─ npm install
├─ npm start
└─ Open http://localhost:4200

STEP 3: TEST FEATURES (1 min)
├─ ✅ Homepage loads
├─ ✅ Chatbot appears
```
